## Contribution workflow demo

- Branch: create a feature branch off the default branch (rehearsal-changes)
- Commit: add docs/demo-notes.md describing the change
- Pull request: open a PR from the feature branch into the default branch
- Self-review: leave a review on your own PR before merging
- Keep current: update the PR branch when the default branch moves ahead
- Merge: land the PR with a clear merge commit message
