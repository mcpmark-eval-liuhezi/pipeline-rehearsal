## Contribution workflow demo

- **Branch**: cut a feature branch (`rehearsal-changes`) off the default branch so `main` stays stable
- **Pull request**: open a PR from the feature branch into the default branch, with a short description of what the change covers
- **Self-review**: leave a review comment on your own PR and work through the checklist before merging
- **Keep current**: when the default branch moves ahead, update the PR branch so it is no longer stale
- **Merge**: land the PR with a clear merge commit, then tidy up
- **Star**: star the repository so it is one click from the starred list during the session
- **Security sweep**: check dependency alerts and code scanning alerts on the merged result
- **Notifications**: clear any threads the rehearsal kicked off
- **Run sheet**: publish the gist recording what actually happened, and link it from the session doc
